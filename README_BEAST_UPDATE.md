# ModuLynx Beast UI update

Drop these files into `Working Prototype/` and run `npm install` then `npm run dev`.

This update intentionally does NOT use `@react-three/postprocessing`, so it stays compatible with the repository's React Three Fiber 8.18 setup.

Features: game-lobby HUD, boot screen, functional nav, procedural 3D laptop, rotate/zoom, X-ray, exploded mode, component selection, compatibility solver, translator, upgrade service flow, Learn Mode, scanner demo and responsive UI.

All hardware values are DEMO/SAMPLE data and must be verified against manufacturer/service documentation before real purchasing or repair decisions.
